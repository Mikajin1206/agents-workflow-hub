## 铁律

**只报告，不改任何代码。**

## 检查项

1. 各仓库是否有未提交改动、未推送提交（`git status`、`git log @{u}..`）。
2. 开着的 PR 哪些超过 3 天没动。
3. 依赖是否有已知高危漏洞（有审计命令就跑，没有就跳过并说明）。
4. CI 是否长期红。

## 输出结构

```
需要你动手的：（按紧急度排序，最多 5 条，每条一行）
- （哪个仓库）出了什么问题，建议怎么做

可以不管的：（一行带过）
```

没有需要动手的就输出一句「今天没有需要你动手的」。
