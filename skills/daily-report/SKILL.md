## 步骤

1. 调 `GET {{hub}}/api/stats` 拿过去 24 小时的台账统计。
2. 调 `GET {{hub}}/api/events?limit=100` 看有没有值得说的异常事件。
3. 调 `GET {{hub}}/api/approvals` 看有没有卡住的批红。
4. 按下面结构写战报。

## 输出结构

```
【今日战报】YYYY-MM-DD

一句话结论：（今天最值得说的一件事）

发生了什么
- …（最多 5 条，每条一行，带数字）

卡住了什么
- …（没有就写「无」）

待你批红
- …（没有就写「无」）

明天建议
- …（最多 3 条）
```

## 硬要求

- 只写事实，不写「整体来看」「综上所述」这类填充句。
- 数字必须来自接口，不要编。
- 全文不超过 400 字。
