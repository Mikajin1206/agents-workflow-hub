## 铁律

**删除任何东西之前必须先票拟。这条没有例外。**

## 巡检项

1. 已合并但没删的远程分支。
2. 超过保留期的日志与报告文件。
3. 引用了不存在 skill 的规则。
4. 超过 90 天没被引用的决定记忆。
5. 死信任务堆了多少。

## 输出结构

先输出**清单**，再输出**票拟内容**：

```
将删除：
- <路径/分支>（原因，大小或数量）

将保留：
- …（有疑问的一律保留）

需要批红：
「准备删除以上 N 项，共 X MB。批准后执行。」
```

## 禁止

- 不要在没有批红的情况下执行任何 `rm`、`git push --delete`、`DROP`。
- 拿不准的一律保留。
