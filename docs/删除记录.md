# 删除记录（过程文件留存册）

> 2026-11-17 定的口径：过程/tmp 文件的清理**不算删除事项**，不需要批红。
> 但「不算事项」不等于「无痕」——所有被清走的过程文件一律**移入**仓库根的
> `tmp/` 目录留存（git 已忽略），并在本表登记一行，保证随时可以回滚。
> 数据库、配置、代码、文档等**真实数据**的删除不适用本表，仍必须先票拟批红。

## 登记格式

| 日期 | 原路径 | 去向（tmp/ 下的路径） | 原因 | 执行人/任务 | 回滚方法 |
| ---- | ------ | --------------------- | ---- | ----------- | -------- |
|      |        |                       |      |             | 移回原路径即可 |

一行一个文件（或一组同批次文件）。`回滚方法` 一般写「移回原路径即可」；
内容被覆盖、无法原样恢复的，必须在登记时写明。

## 什么算「过程文件」（可以走本表）

- 临时文件 / 临时目录（`*.tmp`、`*.bak`、测试运行残留）
- 缓存（构建缓存、依赖缓存、下载缓存）
- 构建产物 / 编译产物（`dist/`、`build/`、`target/` 的重新可生成内容）
- 中间产物（任务执行中产生的草稿、抓取的临时数据）

## 什么不算（必须批红，别动这张表）

- 数据库、数据表、生产/用户/业务数据
- 配置文件、代码、源码、文档
- 密钥与凭证相关的一切
- 分支、提交历史（走 `git push --delete` 也要批红）
